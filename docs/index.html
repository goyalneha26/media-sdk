Media SDK Components

Headless React UI components for building media experiences with complete consumer control over markup, styling and behavior.

Overview Grid Lightbox Reel Swiper Headless Contract Accessibility

Overview

@media-sdk/ui-react is an independent, headless React component library.

Components receive data and callbacks through props and do not communicate with Pexels, media-core, or media-react.

  • Grid
  • Lightbox
  • Reel Swiper

Install

npm install @media-sdk/ui-react

Grid

The Grid component renders a collection of media items. Data fetching remains the responsibility of the consumer.

Example

import { Grid } from "@media-sdk/ui-react";

<Grid
  items={photos}
  getKey={(photo) => String(photo.id)}
  renderItem={(photo) => (
    <img
      src={photo.src.medium}
      alt={photo.alt}
    />
  )}
  onItemClick={(photo) => {
    console.log("Selected:", photo);
  }}
/>

Responsibilities

  • Render media collection
  • Generate stable item keys
  • Render consumer-provided markup
  • Expose item interaction callbacks
  • Support load-more/infinite-scroll behavior

Consumer controls

  • Layout
  • CSS
  • Image presentation
  • Spacing
  • Typography
  • Colors

Lightbox

Lightbox provides a reusable media overlay while leaving the displayed content completely under consumer control.

Example

import { Lightbox } from "@media-sdk/ui-react";

<Lightbox
  open={selectedPhoto !== null}
  onClose={() => setSelectedPhoto(null)}
>
  {selectedPhoto && (
    <img
      src={selectedPhoto.src.large}
      alt={selectedPhoto.alt}
    />
  )}
</Lightbox>

Features

  • Open/close state controlled by consumer
  • Consumer-provided media content
  • Overlay interaction
  • Keyboard/focus handling on web
  • No Pexels dependency

Reel Swiper

Reel Swiper provides vertical snap-style paging and active-item detection for media experiences.

Example

import { ReelSwiper } from "@media-sdk/ui-react";

<ReelSwiper
  items={videos.map((video) => (
    <video
      key={video.id}
      src={video.url}
      controls
    />
  ))}
  onActiveChange={(index) => {
    console.log("Active item:", index);
  }}
/>

Features

  • Vertical media paging
  • Snap behavior
  • Active item detection
  • Consumer-controlled media rendering
  • Works with arbitrary media data

Headless Component Contract

These components intentionally do not ship application-specific styling.

  • No Pexels API calls
  • No media-core imports
  • No media-react imports
  • No authentication logic
  • No API key handling
  • No application-specific visual design

Architecture

Application
    │
    ├── @media-sdk/react
    │        │
    │        └── @media-sdk/core
    │
    └── @media-sdk/ui-react
             │
             └── props + callbacks only

Accessibility

Consumers remain responsible for semantic markup and content presentation while the UI primitives provide interaction behavior.

  • Provide meaningful image alt text
  • Use semantic buttons for interactive controls
  • Provide keyboard-accessible controls
  • Maintain visible focus states
  • Use appropriate labels for media controls
